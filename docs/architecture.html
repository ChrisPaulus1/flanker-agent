4 · What makes it safe to re-run

Cursor advances last

The alert is sent before the version is recorded. A crash in between retries the release; the reverse would lose it forever.

Unique (app_id, version)

The database, not application logic, is what makes a duplicate event physically impossible.

Recoverable half-runs

Event stored but email failed → resend without paying for the LLM again. Both stored → reconcile the cursor, don't re-alert.

Failures are isolated

One competitor failing is reported per-app and never aborts the run. Its cursor stays put for the next tick.
